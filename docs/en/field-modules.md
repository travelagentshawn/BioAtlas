# Modules: Seasonality, Field Identification and Learning

Three independent views extend Explore, Tree of Life, Travel Scenes and the Trip Workbench.

## Seasonal calendar (`#/seasonality`)
Reads the API v1 species list and regions. It displays recommended observation months and supports plant / animal filters. Region activity is based on each region record's monthly species counts. A month is a recorded observation window, not a live bloom forecast or a guarantee of visibility.

## Field identification (`#/identify`)
Filters species by common or scientific name, kingdom, habitat, country and month. Detailed diagnostic traits remain on each species record. Coverage is currently limited and must not be interpreted as a complete local species checklist.

## Field learning (`#/learn`)
Builds four-option recognition exercises from field-mark descriptions already present in species records. Questions and answers come from the API data; the module does not invent additional scientific claims.

## Data status
Existing records remain marked `seed`. These modules preserve their review status and do not present draft records as verified conclusions.
