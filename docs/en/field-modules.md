# Modules: Seasonality and Field Identification

The platform keeps the Field Atlas and Evolution Tree as its two primary browsing experiences. Every tool is listed in a complete, multi-level module directory. The former species-recognition quiz has been removed. Field Identification is now a record-search and reference tool, with no quiz, scoring or multiple-choice flow.

## Seasonal calendar (`#/seasonality`)
Reads the API v1 species list and regions. It displays recorded observation windows by month and supports plant / animal filters. Region activity is based on each region record's monthly species counts. A month is not a live bloom forecast or a guarantee of visibility.

## Field identification (`#/identify`)
Filters species by common or scientific name, kingdom, habitat, country and month. Detailed diagnostic traits remain on each species record. Coverage is currently limited and must not be interpreted as a complete local species checklist.

## Data status
Existing records remain marked `seed`. These modules preserve their review status and do not present draft records as verified conclusions.
