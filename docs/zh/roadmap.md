# 路线图

这里是公开的待办清单。认领前请先开一个 Issue 或在 PR 中说明。

## 数据（最高优先级：核对）

- [ ] 逐条核对 `seed` 记录：文献存在性、DOI、年代区间、IUCN 等级。
- [ ] 为每个类群补充 `external_ids`（GBIF、NCBI Taxonomy、Open Tree、Wikidata），仅写验证过的值。
- [ ] 扩充覆盖：热带雨林、珊瑚礁与海岸、高山草甸、非洲草原、欧洲庭院。

- [ ] 为物种添加有明确许可的照片（`media`）。
