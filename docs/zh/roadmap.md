# 路线图

这里是公开的待办清单。认领前请先开一个 Issue 或在 PR 中说明。

## 数据（最高优先级：核对）

- [ ] 逐条核对 `seed` 记录：文献存在性、DOI、年代区间、IUCN 等级。
- [ ] 为每个类群补充 `external_ids`（GBIF、NCBI Taxonomy、Open Tree、Wikidata），仅写验证过的值。
- [ ] 扩充覆盖：热带雨林、珊瑚礁与海岸、高山草甸、非洲草原、欧洲庭院。
- [ ] 增加菌类、苔藓与真菌——它们是旅途中同样常见的生命。
- [ ] 为物种添加有明确许可的照片（`media`）。

## 模块（延展方向）

- [ ] 物种的“季节日历”视图（物候）与按目的地的月历。
- [ ] 辨认检索：按颜色、大小、栖息地的筛选式检索。
- [ ] 声音：鸟鸣与蛙鸣的可再分发录音链接。
- [ ] 保护与礼仪卡片：当地法规、保护区规则。
- [ ] 学习模式：以系统树为线索的小测验。

## 技术

- [ ] API v1 的 JSON Schema 发布到稳定 URL，便于外部校验。
- [ ] 增加更多语言（`ja` 已在 Schema 中允许）。
- [ ] 无障碍审查（屏幕阅读器下的系统树）。
- [ ] 离线 PWA 与按行程预下载。
