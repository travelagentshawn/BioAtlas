# 功能模块：季节日历、野外辨认与学习

本版本在原有探索、生命之树、旅行场景和行程工作台之外，新增三个独立视图。

## 季节日历（#/seasonality）
读取 API v1 的物种列表与旅行场景，按月份展示推荐观察窗口，并支持植物 / 动物筛选。场景热度使用各场景记录中的月度物种计数。月份只是数据记录的观察窗口，不等同于实时花期或保证可见。

## 野外辨认（#/identify）
按名称、学名、界、栖息地、国家和月份筛选物种。详细形态特征仍以物种档案为准；当前数据量有限，不应将检索结果理解为完整地区物种名录。

## 生命观察学习（#/learn）
从已有物种记录抽取形态辨认线索，生成四选一练习。题目和答案均来自当前 API 数据，不额外生成未经核验的科学事实。

## 数据状态
现有记录仍标记为 seed。三个模块继承记录的审核状态，不会把初稿呈现为已核实结论。
