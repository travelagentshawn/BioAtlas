# 功能模块：季节日历与野外辨认

本平台保留自然图鉴和进化树两项主要浏览体验，并通过完整模块目录提供所有工具入口。原有物种辨认测验已移除；野外辨认现在用于按实际记录检索和查看物种，不设置答题、计分或选择题流程。

## 季节日历（#/seasonality）
读取 API v1 的物种列表与旅行场景，按月份展示记录中的观察窗口，并支持植物 / 动物筛选。场景热度使用各场景记录中的月度物种计数。月份不等同于实时花期预测或保证可见。

## 野外辨认（#/identify）
按名称、学名、界、栖息地、国家和月份筛选物种。详细形态特征以物种档案为准；当前数据量有限，不应将检索结果理解为完整地区物种名录。

## 数据状态
现有记录仍标记为 seed。模块继承记录的审核状态，不会把初稿呈现为已核实结论。
