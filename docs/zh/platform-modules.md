# 自然观察平台模块

本页说明新增模块的范围、数据边界和审核要求。

## 自然地图
`#/map` 使用旅行场景的经纬度中心点绘制等距经纬度定位图，可按国家和月份筛选。它不是物种连续分布图，也不显示海岸线或保护区边界。每个地点链接到完整场景记录与物种月份数据。

## 保护与野外礼仪
`#/conservation` 汇总物种保护等级、评估日期、来源和已有的野外观察礼仪。IUCN 缺失值不代表无危；不同年份的评估不能直接视为当前法规。当地法规、保护区准入和无人机规定必须另行核对主管机构公告。

## 自然声音
`#/sounds` 读取物种记录中的可选 `sounds` 数组。每条录音必须提供 HTTPS 音频地址、原始来源、许可和署名；仅有播放地址或不清楚授权的录音不会进入公开数据。当前没有符合条件的录音时，页面显示贡献提示而不是播放占位音频。

## 演化学习
`#/evolution` 使用当前分类单元之间的父子关系生成共同祖先练习。当前图鉴只覆盖抽样类群，题目不得被解释为完整生命树或正式分类裁决。

## 物种辨认
`#/identify` 支持名称、学名、类群、国家、栖息地、月份、颜色标签和体型区间筛选。颜色标签与厘米体型是可选数据字段；未填充时筛选项不会伪造特征。体型记录应说明测量对象和范围。

## 离线使用
网站提供 PWA manifest 与 Service Worker。首次在线访问后，应用外壳和已访问的数据可被缓存；行程工作台可请求预下载所选地点及关联物种记录。离线缓存仅适用于同源 API；若通过外部 `apiBase` 使用远程 API，需要该 API 自身支持离线数据包或同源代理。

## 语言与无障碍
界面语言切换已增加日语入口，缺少日语翻译的文本暂回退到英文；这不是完整日语本地化。基础无障碍包括键盘焦点、跳过导航、图表替代说明、减少动态效果设置。复杂系统树仍需独立屏幕阅读器审查。

## 数据质量
所有模块继承数据记录的 `review_status`。任何保护等级、物候、分布、录音或法规声明均需记录可追溯来源；初稿不得呈现为已核验事实。
