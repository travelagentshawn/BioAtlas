# プラットフォーム機能

- **自然地図** — 登録済み地域の位置を示すロケーターマップです。連続した生息域ポリゴンや保護区境界を表すものではありません。
- **保全情報** — データに存在する保全評価と、低干渉の観察マナーを集約します。未収集の国別規制を推測しません。
- **自然音** — ライセンス、帰属、元の出典 URL が確認できる録音のみを再生対象とします。未提供の音声は作成しません。
- **進化学習** — 現在の分類ツリーを使って共通祖先を学びます。現在のツリーは全生物の完全な系統樹ではありません。
- **品質ダッシュボード** — 種・分類群・地域、出典、レビュー状態、地域出現証拠のカバレッジを表示します。
- **PWA / オフライン** — アプリシェルと同一オリジン API をキャッシュし、旅行シーン単位で関連データを事前保存できます。外部 API は同一オリジンのプロキシなしではオフライン保存できません。
