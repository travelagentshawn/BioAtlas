# プラットフォーム機能

このページでは、各モジュールの対象範囲、データ上の制約、確認方針を説明します。

## 自然地図
`#/map` は登録済み旅行シーンの座標を等距円筒図法のロケーターマップに表示し、国と月で絞り込みます。連続した生息域や保護区境界を示す地図ではありません。地図上のマーカーは Tab でフォーカスし、Enter または Space でシーン詳細を開けます。下部のシーン一覧にも同じリンクがあります。

## 保全情報と野外マナー
`#/conservation` では IUCN レッドリスト評価と法律・条約による保護を分けて表示します。`conservation.protections[]` は法的文書、管轄、状態、適用範囲、出典、確認日を記録します。これは IUCN のカテゴリーではありません。IUCN データがないことは低リスクを意味せず、保護記録がないことも自由な接触や採集を意味しません。現地法令、保護区への立ち入り、ドローン規制は管轄当局で別途確認してください。

## 海洋分類群とサンゴの保護
初期データには刺胞動物門、花虫綱、六放サンゴ亜綱、イシサンゴ目、ミドリイシ科、ミドリイシ属を追加し、Staghorn coral と Elkhorn coral を収録しています。NOAA の保護情報と ITIS の分類情報は別々の出典で管理し、未確認の IUCN カテゴリーや分岐年代は追加していません。

## 自然音
`#/sounds` は種レコードの任意項目 `sounds` を読み込みます。録音を公開するには HTTPS の音声 URL、元の出典、ライセンス、クレジットが必要です。再配布条件が不明な録音は掲載しません。利用可能な録音がない場合、架空の音声ではなく投稿案内を表示します。

## 進化学習
`#/evolution` は現在の分類群の親子関係を使って共通祖先の練習問題を作成します。図鑑は生命の一部のみを収録しており、完全な系統樹や正式な分類判断ではありません。

## 種の識別
`#/identify` は和名・英名、学名、界、国、生息環境、月、色タグ、体長範囲で検索できます。色タグとセンチメートル単位の測定値は任意項目です。未入力の特徴を推測して表示しません。サイズ情報には測定対象と範囲を記録します。

## オフライン利用
PWA manifest と Service Worker を提供します。オンラインでアクセスした後、アプリシェルと閲覧済みデータをキャッシュできます。旅行プランナーから選択したシーンと関連種の事前保存を要求できます。オフラインキャッシュは同一オリジン API のみ対応し、外部 `apiBase` を使う場合は API 側のオフラインパッケージまたは同一オリジンプロキシが必要です。

## 言語とアクセシビリティ
日本語 UI は段階的に整備中です。未翻訳の文字列は英語にフォールバックするため、完全な日本語対応ではありません。基本機能としてキーボードフォーカス、スキップナビゲーション、図表の代替説明、動きを減らす設定を備えています。自然地図のマーカーは Tab、Enter、Space に対応します。系統樹は図として公開し、階層的な読み上げには「アウトライン」表示を利用してください。スクリーンリーダーによる実機確認は引き続き必要です。

## データ品質
すべてのモジュールはレコードの `review_status` を保持します。保全評価、季節性、分布、録音、法規制の記述には追跡可能な出典が必要です。初稿データを検証済みの事実として表示してはいけません。

## 出典ライブラリと品質ダッシュボード
`#/sources` は引用情報を集約し、種類、著者、タイトル、DOI で検索できます。`#/quality` は種、分類群、旅行シーン、文献、保全評価、外部 ID、ライセンス済みメディア、レビュー状態を集計します。これらの数値は現在のリポジトリの収録状況を示すもので、世界の生物多様性を網羅するものではありません。

- **分類権威の管理** — 品質ダッシュボードには権威ソースの範囲、レコード単位の分類アサーション、未確認の識別子を表示します。各情報源の「受容名」は、その情報源自身の判断として個別に扱います。
