# ロードマップ

## データと科学的検証

- [ ] 既存の `seed` レコードを一件ずつ一次資料と照合する。
- [ ] 地域—種—月の関連に出典を追加し、未確認の月範囲を減らす。
- [ ] 菌類と蘚類の科・属・種、地域カバレッジを拡張する。
- [ ] サンゴ、熱帯雨林、アフリカのサバンナなどの生物相を追加する。
- [ ] 季節性データを現地観察、地域チェックリスト、研究資料で補強する。

## プラットフォーム

- [ ] 実際に再配布可能な自然音をライセンス付きで収録する。
- [ ] 各国・地域のドローンや保護区規制を公式情報から収集する。
- [ ] 日本語 UI とドキュメントの翻訳範囲を拡大する。
- [ ] 系統樹を含む全画面のスクリーンリーダー監査を行う。

## 品質原則

出典がない場合はデータを補作せず、未確認状態を維持します。レビュー監査フィールドがあること自体は、科学的結論の正しさを保証しません。
