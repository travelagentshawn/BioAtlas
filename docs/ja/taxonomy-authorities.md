# 分類権威と学名ガバナンス

BioAtlas は**分類群ごとに権威ある情報源を使い分ける階層型モデル**を採用します。一つのデータベースを、すべての生物群と分類上の判断に対する唯一の最終権威とはしません。

## 役割の違い

| 役割 | 判断を支援する内容 | 単独では決定できない内容 |
| --- | --- | --- |
| グローバル・バックボーン | 広範な名称検索、ID照合、共通の入口 | すべての系統の最終的な専門分類 |
| 命名索引 | 学名の公表・命名規約上の記録 | 普遍的な系統分類や保全状態 |
| 専門チェックリスト | 対象群の受容名と分類 | 対象範囲外の分類 |
| 分類フレームワーク | 特定群・特定版の高次分類 | 範囲外の種の命名上の有効性 |
| 保全評価 | 日付付きの絶滅リスク評価 | 分類上の受容状態 |

## 主な情報源

構造化レジストリは `/api/v1/taxonomic-authorities.json`、各情報源の記録は `data/sources/authority-*.json` にあります。

- **Catalogue of Life Base / XR**：Base は精査済みの世界規模ソースを優先し、XR は追加統合によって網羅性を高めます。GBIF の現在の主要分類は XR を使用します。インポート時は Base と XR を区別して版を固定します。
- **IPNI**：植物名の命名索引。受容種チェックリストとは区別します。
- **POWO**：維管束植物の受容名と分布。アクセス日を記録します。
- **APG IV**：被子植物の目・科の高次分類。使用版を明記します。
- **Index Fungorum / Species Fungorum、MycoBank**：菌類の命名記録。両者のIDや不一致を保持します。
- **IOC World Bird List**：鳥類。正確なリリース番号を保存します。
- **The Reptile Database**：爬虫類。
- **Amphibian Species of the World**：両生類。
- **Mammal Diversity Database**：哺乳類。リリース番号を保存します。
- **Catalog of Fishes**：魚類。
- **WoRMS**：海洋生物。AphiaID とアクセス日を保存します。
- **ITIS / NCBI Taxonomy**：補助的なID照合と分類参照であり、全生物群の唯一の裁定者ではありません。
- **IUCN Red List**：分類権威ではなく、独立した日付付き保全評価です。

GBIF Backbone Taxonomy は旧IDの照合と互換性のためだけに保持します。GBIF の技術文書によると、更新は終了し、主要な分類体系は COL XR に移行しました。旧IDは後方互換性のため引き続き利用できます。

## レコード単位の分類アサーション

Taxon と Species は `taxonomic_assertions[]` を持てます。各アサーションには権威ID、正確なレコードID、情報源の学名、名称状態（`accepted` / `synonym` / `unresolved` / `unassessed`）、任意の分類体系・版、実際の確認日、根拠となる出典を記録します。

既存の引用からIDだけを移した場合、実際の権威レコードを再確認するまでは `unassessed` とします。IDが存在することは受容名である証明にはなりません。異なる情報源の主張は上書きせず併存させます。

## 選択・競合・更新

1. 情報源は知名度ではなく、分類群の範囲と判断の種類に基づいて選びます。
2. 命名上の有効性、受容名、分類概念、系統分類を区別します。
3. 不一致がある場合は双方の主張を保持し、最新の専門文献と一次分類学文献に照らして説明します。
4. 情報源、正確なID、版、アクセス日を保持し、古い主張を黙って削除しません。
5. 大量インポートや名称・親分類の一括置換には、差分レビューと明示的な承認が必要です。情報源が更新されても `seed` を自動的に `reviewed` に昇格させません。
