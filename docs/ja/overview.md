# BioAtlas 概要

BioAtlas は、旅先で出会う植物・動物・菌類を記録するオープンな生物多様性フィールドアトラスです。分子系統学と伝統的な分類学をつなぎ、種・系統・地域・季節を同じデータモデルで扱います。

## 基本方針

- ソースコードと構造化データを公開し、特定の AI モデルやプラットフォームに依存しません。
- UI、データ、API 契約を分離し、他のアプリや AI からも利用できるようにします。
- 科学的な主張には出典を付け、未確認データを検証済みとして表示しません。
- 写真・音声などのメディアは、再配布ライセンスと帰属表示を確認したものだけを扱います。

## 現在の状態

初期の分類・種・地域データは `seed`（未独立検証）です。これは公開された初稿であり、専門家による承認を意味しません。レビュー状況と出典の不足は品質ダッシュボードに表示します。

## 主な機能

生命の樹、種の探索、野外識別、季節カレンダー、自然地図、旅行シーン、保全情報、自然音、進化学習、科学的出典、旅行チェックリスト、オフライン対応。
