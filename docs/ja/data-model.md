# データモデル

## 主なレコード

- **Taxon** — 分類階級、親ノード、系統情報、名称、出典、レビュー状態。
- **Species** — 学名、各言語名、識別形質、進化情報、観察季節、生息環境、分布、外部 ID、出典。
- **Region** — 目的地または繰り返し観察されるシーン。各種の出現月と頻度を持ちます。
- **Source** — 論文、書籍、データベース、ウェブ資料の引用情報。

## 界の扱い

`kingdom` は `plantae`（植物）、`animalia`（動物）、`fungi`（菌類）をサポートします。`root` は真核生物の共通根ノードです。ウマスギゴケなどの蘚類は植物界に含め、菌類とは区別します。

## レビュー監査

`review_status` は `seed`、`reviewed`、`expert-reviewed` を使用します。 `review` オブジェクトには実際のレビュー日、レビュアー、方法、確認範囲、出典を記録します。`expert-reviewed` は専門家による `expert-assessment` が記録されている場合に限ります。

## 地域出現の証拠

各 `Region.species[]` には任意の `evidence` を付けられます。現地観察、公開論文、地域チェックリスト、データベース記録、専門家評価を区別します。証拠がない月範囲は未確認として扱い、確定した地域フェノロジーとみなしません。

## 分類アサーションと権威レジストリ

Taxon と Species は `taxonomic_assertions[]` を持てます。各アサーションには権威レジストリID、提供元の正確なレコードID、提供元の学名、名称状態、任意の分類体系・版、アクセス日、根拠となる出典を保存します。IDを移行しただけで提供元の記録を再確認していない場合は `unassessed` を使用します。異なる権威の主張は上書きせず併存させます。`authority_role` を持つ出典レコードから `api/v1/taxonomic-authorities.json` が生成されます。[分類権威と学名ガバナンス](taxonomy-authorities.md)を参照してください。
