# アーキテクチャ

BioAtlas は UI、構造化データ、API 契約の三層を分離しています。

1. **Data** — `data/` に分類群、種、地域、出典を一件一ファイルの JSON として保存します。
2. **Schema** — `schema/` が各レコードの構造と許容値を定義します。
3. **Contract** — `contract/api-v1.schema.json` と `contract/endpoints.json` が UI とデータの唯一の接点です。
4. **UI** — `ui/` は生成された API v1 のみを読み込みます。

`npm run build:api` はデータから静的 API を生成し、`npm run build:ui` は UI を出力します。外部アプリは API 契約を実装すれば、内部の UI 技術や AI モデルに依存せずデータを利用できます。

## 変更方針

- 既存フィールドを削除・意味変更せず、可能な限り追加的な変更にします。
- データの意味を変える変更には、スキーマ、API 契約、ドキュメント、テストを同時に更新します。
- 本番へのマージや公開前に、差分とデータ影響を確認します。
