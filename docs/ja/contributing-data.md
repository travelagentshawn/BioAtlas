# データ提供と科学的ルール

## 出典

新しい科学的主張には、確認可能な出典を付けてください。出典 ID は `data/sources/` に存在する必要があります。DOI、著者、発行年、データベース ID を推測してはいけません。

## 地域出現の記録

地域と種の関連を追加・変更するときは、可能な限り各関連に `evidence` を付けます。証拠の種類は現地観察、公開論文、地域チェックリスト、データベース記録、専門家評価を区別します。国単位の分布情報だけで、特定の観光地や月の出現を推定してはいけません。

## レビュー状態

- `seed` — 初稿。独立した検証は未完了。
- `reviewed` — 貢献者が引用元と照合した状態。レコード内に `review` を記録し、既存の出典 ID を少なくとも一つ含めます。現地観察も追跡可能な観察記録として登録し、公開論文のように扱ってはいけません。
- `expert-reviewed` — 専門家による評価が記録されている状態。専門家の実際の確認なしに設定してはいけません。

AI が作成した文章を、現地観察や人間の専門家レビューとして記載してはいけません。

## メディア

画像・音声には HTTPS URL、ライセンス、帰属表示、元の出典 URL が必要です。ライセンスを確認できない素材は追加しないでください。
