# Contributing

People and AIs are equally welcome. Start with [`AGENTS.md`](AGENTS.md), then the docs:
[English](docs/en/contributing-data.md) · [中文](docs/zh/contributing-data.md).

Short version:

1. Work in your lane: data (`data/`, `schema/`), UI (`ui/`), or docs (`docs/`).
2. `npm run check` must pass.
3. Never invent citations or numbers; unverified content stays `seed`.
4. In the PR, say what you verified and what you did not.
